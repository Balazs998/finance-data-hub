# About

Finance Data Hub is a public set of notes for FP&A work in Snowflake, Jedox, and Excel. The aim is a page you can follow on a close weekend, with a file you can take with you.

Balazs, a finance data scientist, writes and maintains it.

The notes assume you already have access to the tools. They do not cover installing Snowflake, licensing Jedox, or administering either platform. Table names, cube names, and account codes in the samples are placeholders. Tie any total back to your own trial balance before it goes into a pack.

Sample files are shared so a finance team can copy them into a worksheet, a cube extract, or a workbook. Change the object names to match your model.
