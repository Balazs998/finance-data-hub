Finance Data Hub is a public set of notes for FP&A work in Snowflake, Jedox, and Excel. The aim is a page you can follow on a close weekend, with a file you can take with you.

The notes assume you already have access to the tools. They do not cover installing Snowflake, licensing Jedox, or administering either platform. Table names, cube names, and account codes in the samples are placeholders, and every company, figure and person in them is fictional. Tie any total back to your own trial balance before it goes into a pack.

Sample files are shared so a finance team can copy them into a worksheet, a cube extract, or a workbook. Change the object names to match your model.

## How the notes are checked

Each note is checked against the vendor's official documentation, and every total is recomputed from the sample files. A note that hasn't been run on a live Snowflake account, Jedox install or Excel workbook says so in a box at the top.

## Privacy

This site counts page views with [GoatCounter](https://www.goatcounter.com/help/privacy), which doesn't use cookies and doesn't store IP addresses or any tracking ID. It keeps only aggregate counts, such as views per page, browser and country. Blocking `gc.zgo.at` in your browser or content blocker turns the counting off.
